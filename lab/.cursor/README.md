# Catálogo do Contexto

## Mecanismos Cursor

- `rules/`: Project Rules nativas.
- `agents/`: agentes especializados.
- `skills/`: Agent Skills.
- `hooks.json`: eventos e scripts suportados pelo host.
- `mcp.json`: exemplo sem credenciais.

## Convenções do laboratório

- `playbooks/`: coordenação carregada por referência explícita.
- `knowledge/`: fundamentação consultiva.
- `contracts/`: contratos e schemas canônicos.
- `evals/`: casos, assertions e fixtures.
- `evidence/`: fatos e vereditos de execuções identificadas.
- `hooks/`: scripts determinísticos chamados pelo operador ou por hooks configurados.

## Fonte canônica

Não duplique estes artefatos em `ai-context/`, `.agents/` ou outra árvore concorrente.
