# Critérios Semânticos

## Use julgamento semântico

- Para equivalência de sentido por paráfrase.
- Para contradição indireta de uma proibição.
- Para adequação de uma justificativa à fonte recuperada.

## Use validação determinística

- Presença de campo ou ID.
- Conformidade JSON Schema.
- Ordem registrada em trace.
- Status, código de saída e igualdade de valores.

## Veredito

- `PASS`: evidência suficiente e compatível.
- `FAIL`: violação ou contradição comprovada.
- `INCONCLUSIVE`: faltam fatos para decidir.
